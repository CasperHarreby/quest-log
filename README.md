# Quest Log

A single-page, gamified weekly goal tracker. Earn XP and level up by completing daily and weekly quests.

**Live app:** https://casperharreby.github.io/quest-log/

## What it is

- Pick quests for today and for the week
- Check them off to earn XP
- Level up through ranks (Novice → Legend)
- Streak counter for consecutive days with completed quests

No account, no backend. Data lives in your browser's localStorage.

## Files

- `index.html` — the entire app (HTML + CSS + JS, ~700 lines, no build step)

## Deploying changes

Edit `quest-log.html`, then:

```bash
git add index.html
git commit -m "describe your change"
git push
```

GitHub Pages redeploys automatically within ~1 minute.
